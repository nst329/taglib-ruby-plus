# 2.3.2.12のバイナリgem検証

## 変更とビルド

複数trefの独立修復、chapter時間診断・明示profile修復、index 0のraw保持保存を2.3.2.12としてまとめた。時間fingerprintとmetadata準備をprivate関数へ分離し、raw保持計画をfreezeした。

既存のborrowed wrapperテストの+1は新規bindingでも再現した。CoverArtListの非const beginによるdetachが登録済みアドレスと解除アドレスを変えていたため、const走査へ変更して解消した。closeとitem削除後の借用CoverArt利用拒否も回帰テストに追加した。

パッチ済みlegacy TagLibを新規Release/arm64/macOS target 12.0で構築し、Ruby 4.0.7用の11拡張を隔離ビルドした。TagLibの0001〜0004を配布sourceとビルド手順へ含めた。Homebrewのnative libraryは変更していない。

## 検証

| 項目 | 結果 |

| Items/lifetime最終対象テスト・legacy | 30 tests / 107 assertions、失敗0・エラー0 |
| Items/lifetime最終対象テスト・grouped | 30 tests / 107 assertions、失敗0・エラー0 |
| gemspec一覧・Ruby構文・差分空白 | 成功 |

実ファイル010226_001はコピーだけを操作し、欠落参照3件除去・音声2→章4保持・時間atomのv1昇格・raw保持タグ保存2回を確認した。15章と全mdatが保持され、ffprobeはpadding込み16サンプルを返した。外部原本のSHA-256不変を確認した。

配布gemをprivate tmpの専用gem homeへinstallして検証した。実行時Rubyコードのsource_locationと11bundleのload先は配布gem内にある。DYLD_PRINT_LIBRARIESで同梱libtag.2.dylibのloadを確認した。11bundleと同梱libtagの実体をMach-O検査し、arm64、minos=12.0、同梱用RPATH、外部build prefix/librubyへの依存なしを確認する。

調査用Debugビルドはminos=host SDKを継承していたため配布に使っていない。packagingでは絶対build RPATHを除去し、aliasが実体化したlibtagも含めてinstall nameを@rpathへ揃える。最終再packagingはこの修正と文書だけで、製品Ruby/nativeコードは全体テスト済みのものと同じ。再構築後は依存検査、load、修復対象テストを確認する。
