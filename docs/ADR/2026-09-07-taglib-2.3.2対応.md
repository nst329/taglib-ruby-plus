# ADR: TagLib 2.3.2 へ最低要求を更新する

## 状況

TagLib 2.3.2 が公開され、MP4 チャプターのトラック参照処理、不正 atom の検査、複数のコーデック判定が改善された。プロジェクトは現在 TagLib 2.3.1 以上を要求している。

## 決定

- TagLib の最低要求を 2.3.2 に引き上げる。
- taglib-ruby-plus のバージョンを 2.3.2 にする。
- MP4 の追加コーデック定数と `Properties#codec_id` を Ruby API として公開する。
- MP4 チャプターの実装は上流 TagLib の修正を利用し、同じ処理を Ruby 側へ複製しない。

## 理由

MP4 チャプターの追加・削除時に既存の `tref` を保持する修正は、このプロジェクトの `save_chapters` に直接影響する。最低バージョンを固定しないと、修正済みの保存結果を保証できない。追加コーデック情報はヘッダーで公開されるため、既存の MP4 properties ラッパーへ小さく追加できる。

## 影響

- TagLib 2.3.1 以下ではインストール時のネイティブ拡張ビルドが失敗する。
- MP4 の追加コーデックを enum と sample description の識別子で取得できる。
- MP4 チャプター保存の互換性と不正ファイルへの耐性が TagLib 2.3.2 の実装に更新される。
